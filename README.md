# 🏠 HomeForce CRM

Sistema de gestão imobiliária desenvolvido na plataforma Salesforce, com foco na organização de empreendimentos, lotes, clientes e processos relacionados à gestão imobiliária.

## 📌 Sobre o projeto

O HomeForce CRM foi desenvolvido como um projeto prático para aplicar conhecimentos de desenvolvimento e configuração na plataforma Salesforce.

A solução busca centralizar informações e automatizar processos relacionados à gestão imobiliária, utilizando recursos declarativos e desenvolvimento Apex/LWC.

## 🚀 Funcionalidades

- Cadastro e gerenciamento de empreendimentos
- Gestão de lotes
- Controle de informações de clientes
- Gestão de processos imobiliários
- Automação de processos com Salesforce Flow
- Regras de validação
- Controle de acesso e permissões
- Relatórios e dashboards
- Componentes personalizados em Lightning Web Components
- Lógica de negócio utilizando Apex

## 🛠️ Tecnologias utilizadas

- Salesforce Platform
- Apex
- Lightning Web Components (LWC)
- Salesforce Flow Builder
- SOQL
- Custom Objects
- Validation Rules
- Record Types
- Permission Sets
- Reports & Dashboards
- Salesforce DX
- Visual Studio Code
- Salesforce CLI
